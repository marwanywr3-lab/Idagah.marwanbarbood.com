آي-دقة - ملفات الموقع
1) ارفع كل محتويات هذا المجلد (index.html و manifest.json و sw.js ومجلدي icons و fonts) في جذر المستودع على GitHub.
2) فعّل GitHub Pages من Settings > Pages.
3) افتح الرابط من الجهاز: أول مرة يطلب منك تحديد رمز لوحة الطلبات.
4) ثبّت التطبيق: Chrome > القائمة > "تثبيت التطبيق" (أو "إضافة إلى الشاشة الرئيسية").
ملاحظة: الطلبات والرمز محفوظة على نفس الجهاز، فاستخدم نفس الجهاز والمتصفح دائماً، ولا تمسح بيانات الموقع.
عند تعديل أي ملف، غيّر رقم النسخة CACHE في sw.js.
